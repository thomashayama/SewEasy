# U3M 1.1 reference files

The two unmodified schemas, `cupro_physics.json` (upstream
`physics_example2.json`), and `shirley_physics.json` (upstream
`physics_example.json`, file revision `836762f2a46194dd2a21b5df8fc41066a1c525ef`)
come from [Vizoo's U3M repository](https://github.com/vizoogmbh/u3m/tree/master/u3m1.1).
They are covered by the accompanying BSD 3-Clause LICENSE.

The sample is Browzwear's SU-1098 Cupro measurement dataset. The minimal U3M
material wrapper is generated by SewEasy, not a vendor-exported material.
There are no sample appearance textures. It is a format test, not a claim
that these measurements describe every cupro fabric.

The second fixture is Browzwear's **QA Test Fabric shirley**, a 300 g/m²
cotton knit with string-valued mass and low-force warnings on both bending
axes. Tests wrap the unchanged JSON in a SewEasy material manifest. This is
a published QA dataset, not a verified supplier product or calibrated cotton preset.

Specifications checked: `spec/u3m_schema.json`, `physics/physics_schema.json`,
`spec/u3m_additional_spec_u3ma.txt`, and the two raw-physics PDFs in `physics/`.
Imported source bytes remain unchanged; edits are exported in standard
weight/thickness fields and a `custom.seweasy` extension.
